# Qazvin Traditional Sweets | Custom E-Commerce Platform

**Type:** Custom E-Commerce Website  
**Role:** AI-assisted custom web implementation  

---

## Project Overview
A custom online store implemented using AI-assisted development workflows for a traditional Persian sweets brand in Qazvin. This project was developed without any CMS or e-commerce builders (like WordPress/WooCommerce) to provide a completely tailored experience and a tailored architecture for the client.

## My Contribution
- Used AI-assisted development to read, test, troubleshoot, adapt, and integrate the platform's front-end and back-end code.
- Implemented a custom admin dashboard for the non-technical business owner to manage products, categories, orders, users, and dynamic site content.
- Implemented a customer account panel with order tracking and personalized UI themes (color and dark mode).
- Implemented a cart and order-submission system without online payment, using a 6-stage order status workflow.
- Worked on security controls including PDO prepared statements, CSRF protection, session handling, and file-upload validation; these are implementation details, not an independent security audit.

## Technologies Used
- **Backend:** PHP, MySQL, PDO
- **Frontend:** Vanilla JavaScript, HTML5, CSS3 (Custom Design System)
- **Environment:** Shared cPanel Hosting
