# Qazvin Traditional Sweets | Custom E-Commerce Platform

**Type:** Custom E-Commerce Website  
**Role:** Full-Stack Developer  
**Live Demo:** [hamidtc.shop](https://hamidtc.shop)

---

## Project Overview
A fully custom online store built from scratch for a traditional Persian sweets brand in Qazvin. This project was developed without any CMS or e-commerce builders (like WordPress/WooCommerce) to provide a completely tailored experience and a lightweight, secure architecture for the client.

## My Contribution
- Designed and developed the entire platform from scratch.
- Built a secure custom admin dashboard for the non-technical business owner to manage products, categories, orders, users, and dynamic site content.
- Implemented a customer account panel with order tracking and personalized UI themes (color and dark mode).
- Developed a secure cart and checkout system without online payment, using a 6-stage order status workflow.
- Ensured high security standards using PDO prepared statements, CSRF protection, secure session management, and strict file-upload validation.

## Technologies Used
- **Backend:** PHP, MySQL, PDO
- **Frontend:** Vanilla JavaScript, HTML5, CSS3 (Custom Design System)
- **Environment:** Shared cPanel Hosting
